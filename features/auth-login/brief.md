# Auth Login

What is it: The sign-in screen for a web app. Email/password plus a passkey option, and an SSO fallback.
Who uses it: Returning users on desktop and mobile, most on a saved-password autofill.
Must include: Email field, password field, "Continue with SSO" button (no third-party logos — text only), passkey/biometric option, "forgot password" link, link to sign up.
Tone/style: Calm, trustworthy, fast — no marketing copy, this is a utility screen.
Brand: neutral (using the default tokens)
Reference: none — no photography or stock imagery; use CSS gradients and inline SVG only. Do not draw any third-party logos (Google/Apple/GitHub/Microsoft); SSO is a single generic "Continue with SSO" button.
